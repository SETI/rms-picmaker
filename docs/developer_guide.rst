Developer Guide
===============

This guide is for contributors and maintainers of ``rms-picmaker``.
It complements the :doc:`user_guide` (which is end-user facing) and
the :doc:`module` reference (which is the auto-generated API).

If you only want to convert images, read the User Guide. If you want
to understand the pipeline, change the code, or release a new
version, read this.
